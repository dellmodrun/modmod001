よくある質問

全般

  • Formant とは何ですか？

    セキュリティリサーチャーが立ち上げた、AI ネイティブのオフェンシブセキュリティ企業です。Red は組織全体をテストし、Whitebox は 1 つのアプリケーションを深くペンテストし、Review はすべてのプルリクエストをチェックします。

  • Formant はスキャナーと何が違いますか？

    スキャナーは、誤りかもしれないパターンを指摘します。Formant は攻撃者がコードをどう悪用するかを推論し、悪用可能だと示せるものだけを報告します。

  • Formant はどんな脆弱性を見つけてきましたか？

    PHP、Node.js、Metabase Cloud のリモートコード実行、OpenAI の内部リポジトリへの侵入経路、Bash の上流リポジトリにコードをプッシュする方法などです。研究記事を読む。

  • Formant はどの言語に対応していますか？

    あらゆる言語に対応しています。以下の言語では、言語を考慮したより深い分析を行います。お使いの言語が載っていない場合は、デモを予約いただければ対応状況を確認します。

Red

  • Formant のレッドチーム演習は何を対象にしますか？

    組織の攻撃対象領域全体を継続的に対象とします。Formant は、外部サービス、認証、SaaS プロバイダー、サプライチェーン、機能、コンポーネントの最新のモデルを維持し、新しい資産が現れるとテストします。

  • ペンテストとは何が違いますか？

    ペンテストは、固定されたスコープを 1 回テストします。レッドチーム演習は常に実行されるため、新しい資産や新たに公開された脆弱性は現れた時点でテストされます。

  • テストは安全ですか？

    はい。破壊的な操作は禁止されており、リサーチャーがエージェントを監視しています。テストが可用性に影響する可能性がある場合は、作業を止めてご連絡します。

  • 修正が有効かどうか確認しますか？

    はい。Formant は攻撃を再実行し、経路がふさがれたことを確認します。

  • バグバウンティとは何が違いますか？

    バグバウンティは、外部のリサーチャーが報告したものに報奨金を支払います。Red は、インシデントや報奨金の支払いになる前に、完全な攻撃経路を継続的に実証します。

Whitebox

  • ホワイトボックスペンテストには何が含まれますか？

    ソースコードに基づく 1 つのアプリケーションのペンテストで、動的テストもオプションで追加できます。リサーチャーがすべての検出結果を検証し、技術レポートとエグゼクティブレポート、修正ガイダンス、実施証明書、無料の再テストが提供されます。

  • レポートは SOC 2 や ISO 27001 に使えますか？

    はい。SOC 2、ISO 27001、顧客のセキュリティ審査におけるペンテストの証跡として使えます。

Review

  • Formant はどのようにプルリクエストをレビューしますか？

    各プルリクエストやマージリクエストにセキュリティチェックを投稿し、該当する行にコメントします。@hacktron review とコメントすると再実行でき、検出結果はスレッド内でトリアージできます。

    pkg/middleware/healthcheck.go

    func isHealthCheckRequest(paths, userAgents map[string]struct{}, req *http.Request) bool { if _, ok := paths[req.URL.EscapedPath()]; ok { return true } if _, ok := userAgents[req.Header.Get("User-Agent")]; ok { return true } return false }

    hacktron-app Bot

    High Authentication Bypass via Spoofable User-Agent Header in Health Check Middleware

    The health check middleware in oauth2-proxy determines if a request should bypass authentication by checking if the User-Agent header matches a configured value (ping-user-agent). Since the User-Agent header is entirely controlled by the client, an attacker can spoof this header to match the configured value, thereby bypassing authentication for any arbitrary path. This allows unauthenticated access to the protected upstream service.

    Triage: Reply !fp (false positive), !valid (confirmed), or !accepted_risk. Any other reply is saved as a triage note.

  • Formant がコードを修正してくれますか？

    依頼した場合のみ修正します。Formant が修正を作成し、テストを実行して、チームがレビューできるようプルリクエストを作成します。マージすることはありません。

  • どのソース管理プラットフォームに対応していますか？

    GitHub（GitHub Enterprise Server を含む）、GitLab、Azure DevOps、Bitbucket に対応しています。

  • コードベースに関するコンテキストを Formant に与えられますか？

    はい。.hacktron/rules.md ファイルを追加するか、コンテキスト文書をアップロードしてください。トリアージのフィードバックからも学習します。

連携

  • Formant はどのツールと連携しますか？

    Slack では、アラート、トリアージ、スレッド内での質問に対応します。@Formant AI をメンションすれば、変更について質問したり、CVE がリポジトリに影響するか確認したり、ペンテストを設定したりできます。チケット管理には Jira と Linear に対応しています。

  • API はありますか？

    はい。組織単位のキーを使う REST API に加え、MCP サーバーと Slack アシスタントがあります。

  • 検出結果をエクスポートできますか？

    はい。エグゼクティブレポートと技術レポートをダウンロードしたり、検出結果を CSV、SARIF、JSON 形式でエクスポートしたりできます。

導入とアクセス

  • Formant をオンプレミスで実行できますか？

    はい。オンプレミス版は、エアギャップ環境を含め、お客様自身のインフラ内ですべて動作します。

  • Formant はどのようにソースコードにアクセスしますか？

    クラウドスキャンでは、リポジトリを隔離環境にクローンし、検出結果を関連するコードスニペットとともにお客様のアカウントに保存します。オンプレミス版では、コードはお客様の環境から出ません。

  • コードが AI モデルの学習に使われますか？

    いいえ。当社の AI プロバイダーである OpenAI、Anthropic、Google は Formant のデータで学習することが認められておらず、ゼロデータリテンション契約によりデータを保存しません。

  • どうやってログインしますか？

    メールアドレスとパスワード、または SAML シングルサインオンでログインします。管理者は組織内の全員に MFA を必須にできます。

  • Formant は SOC 2 に準拠していますか？

    はい。Formant は Insight Assurance による SOC 2 Type 1 と Type 2 のレポートを取得しています。トラストセンターでアクセスをリクエストしてください。

料金

  • 無料トライアルはありますか？

    はい。Review には 14 日間の無料トライアルがあります。

  • Formant の料金体系は？

    Review は開発者 1 人あたりの月額、Whitebox はコードの規模に応じたペンテスト単位、Red は組織単位の料金です。料金をご覧ください。

  • Formant はオープンソースに無料ですか？

    はい。条件を満たす公開リポジトリは Review を無料で使えます。オープンソースのページから申し込む。
