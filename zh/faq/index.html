常见问题

概览

  • Formant 是什么？

    一家由安全研究员创立的 AI 原生进攻性安全公司。Red 测试整个组织，Whitebox 深度渗透测试单个应用，Review 检查每个 PR。

  • Formant 和扫描器有什么区别？

    扫描器标记的是可能有问题的代码模式。Formant 推演攻击者会怎样利用代码，只报告能证明可利用的漏洞。

  • Formant 发现过哪些漏洞？

    PHP、Node.js 和 Metabase Cloud 中的远程代码执行，一条通往 OpenAI 内部仓库的路径，以及一种向 Bash 上游仓库推送代码的方法。阅读研究文章。

  • Formant 支持哪些编程语言？

    所有语言都支持，下列语言还有更深入的专项分析。没有您用的语言？预约演示，我们帮您确认支持情况。

Red

  • Formant 的红队测试覆盖哪些范围？

    持续覆盖组织的整个攻击面。Formant 维护一份实时更新的资产模型，涵盖外部服务、身份认证、SaaS 供应商、供应链、功能和组件，新资产一出现就测试。

  • 和渗透测试有什么区别？

    渗透测试只针对固定范围测一次。红队测试持续进行，新资产和新披露的漏洞一出现就会测试。

  • 测试安全吗？

    安全。严禁破坏性操作，安全研究员全程监控智能体；测试一旦可能影响可用性，我们会立即停止并联系您。

  • 你们会验证修复是否有效吗？

    会。Formant 会重新发起攻击，确认路径已封堵。

  • 和漏洞赏金有什么区别？

    漏洞赏金为外部研究员报告的任何问题付费。Red 持续验证完整的攻击路径，赶在它们演变成安全事件或赏金支出之前。

Whitebox

  • 白盒渗透测试包含哪些内容？

    基于源代码对单个应用做渗透测试，可选动态测试。安全研究员复核每个漏洞，交付技术报告和管理层报告、修复指导、测试证明函，以及一次免费复测。

  • 报告能用于 SOC 2 或 ISO 27001 吗？

    能。报告可作为 SOC 2、ISO 27001 和客户安全评估的渗透测试证明材料。

Review

  • Formant 如何审查 PR？

    它会发布一项安全检查，并在每个 PR 或 MR 的相关代码行上发表评论。评论 @hacktron review 即可重新运行，也可以直接在讨论串中研判漏洞。

    pkg/middleware/healthcheck.go

    func isHealthCheckRequest(paths, userAgents map[string]struct{}, req *http.Request) bool { if _, ok := paths[req.URL.EscapedPath()]; ok { return true } if _, ok := userAgents[req.Header.Get("User-Agent")]; ok { return true } return false }

    hacktron-app Bot

    High Authentication Bypass via Spoofable User-Agent Header in Health Check Middleware

    The health check middleware in oauth2-proxy determines if a request should bypass authentication by checking if the User-Agent header matches a configured value (ping-user-agent). Since the User-Agent header is entirely controlled by the client, an attacker can spoof this header to match the configured value, thereby bypassing authentication for any arbitrary path. This allows unauthenticated access to the protected upstream service.

    Triage: Reply !fp (false positive), !valid (confirmed), or !accepted_risk. Any other reply is saved as a triage note.

  • Formant 能帮我修复代码吗？

    只在您要求时修复。Formant 会编写修复、跑仓库测试，并提交 PR 供团队审查，从不自行合并。

  • 支持哪些代码托管平台？

    GitHub（含 GitHub Enterprise Server）、GitLab、Azure DevOps 和 Bitbucket。

  • 能给 Formant 提供代码库的背景信息吗？

    可以。添加 .hacktron/rules.md 文件，或上传背景文档。研判反馈也会让它持续学习。

集成

  • Formant 能和哪些工具配合使用？

    Slack 用于告警、研判和讨论串内提问：@Formant AI 即可询问某次变更、排查仓库是否受某个 CVE 影响，或安排一次渗透测试。Jira 和 Linear 用于工单。

  • 有 API 吗？

    有。提供使用组织级密钥的 REST API，以及 MCP 服务器和 Slack 助手。

  • 能导出漏洞吗？

    能。可以下载管理层报告和技术报告，或将漏洞导出为 CSV、SARIF 或 JSON。

部署与访问

  • 能私有化部署 Formant 吗？

    能。私有化部署版完全运行在您自己的基础设施中，包括物理隔离环境。

  • Formant 如何访问我的源代码？

    云端扫描会把仓库克隆到隔离环境中，漏洞连同相关代码片段保存在您的账户中。私有化部署版的代码始终留在您的环境中。

  • 我的代码会被用来训练 AI 模型吗？

    不会。我们的 AI 供应商 OpenAI、Anthropic 和 Google 不得用 Formant 的数据训练模型，零数据保留协议也确保它们不会存储这些数据。

  • 如何登录？

    使用邮箱和密码，或 SAML 单点登录。管理员可以要求组织内所有人启用 MFA。

  • Formant 符合 SOC 2 要求吗？

    符合。Formant 已获得 Insight Assurance 出具的 SOC 2 Type 1 和 Type 2 报告。在信任中心申请查看。

定价

  • 有免费试用吗？

    有。Review 可免费试用 14 天。

  • Formant 怎么收费？

    Review 按开发者按月计费，Whitebox 按次计费、价格取决于代码规模，Red 按组织计费。详见定价。

  • 开源项目可以免费用吗？

    可以。符合条件的公开仓库可免费使用 Review。前往开源计划页面申请。
