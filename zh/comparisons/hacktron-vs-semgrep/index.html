Formant vs Semgrep
vs

Semgrep 指出该改什么，Formant Review 讲清攻击者怎么利用，并在漏洞所在行附 PoC（概念验证）。Formant Whitebox 还能对应用做渗透测试，Semgrep 做不到。

对比
Formant Semgrep
范围 Red 测试整个组织，Whitebox 测试单个应用，Review 检查每个 PR。 Semgrep Code 检测自有代码，Supply Chain 检测依赖和恶意软件，Secrets 检测凭据泄露。
分析方式 Review 结合已接入代码库的调用图审查每次变更，能发现改动行之外的漏洞。 确定性静态分析处理常见问题，AI 分析处理业务逻辑漏洞等复杂缺陷。
漏洞报告 直接在漏洞所在代码行发表行内评论，附攻击路径、PoC（概念验证）和修复提示词。 在 PR 和 MR 中评论，附分步修复说明。
持续学习 根据代码、规则文件和补充文档构建威胁模型。开发者可通过回复把漏洞标记为误报、已接受风险、有效或已修复。 从研判结果中学习。记忆功能按项目和规则定制修复建议。
修复 每个漏洞都附带提示词，可在 Cursor、Claude 或 Codex 中打开修复。使用 Remediation，Formant 的智能体会验证漏洞、修复、补充测试并提交 PR。 为 Code 和 Supply Chain 的问题生成代码修改，并提交 PR 或 MR。
渗透测试 Whitebox 基于源代码测试单个应用，开启动态测试时还会测试线上应用。含一次免费复测和测试证明函。 未列出。

超额 每多一个 PR 收 1 美元，默认关闭。 未列出。

常见问题

选择 Formant 能带来什么？

每个漏洞都说明攻击者如何在代码库中利用它，并在漏洞所在行给出攻击路径、PoC 和修复。Whitebox 还能基于源代码对应用做渗透测试，50 美元起。

Whitebox 渗透测试包含哪些内容？

基于源代码对单个应用做渗透测试，可选对线上应用做动态测试。交付技术报告和管理层报告、修复指导、测试证明函，以及一次免费复测，可作为 SOC 2、ISO 27001 和客户安全评估的渗透测试证明材料。价格为 50 至 25,000 美元，每 10 万行代码约 500 美元。

Review 检查哪些问题？

业务逻辑漏洞、越权访问、注入、提示词注入、内存安全漏洞、基础设施即代码（IaC）暴露、供应链风险和密钥泄露。

Review 支持哪些 Git 平台？

GitHub、GitHub Enterprise Server、GitLab、Azure DevOps 和 Bitbucket。漏洞也会同步到 Slack、Jira 和 Linear。
