Analyse de paquets

Nous lisons votre fichier de verrouillage dans votre navigateur et vérifions chaque paquet et chaque version parmi les plus de 21 000 bulletins de malware d’osv.dev. Le fichier n’est jamais stocké ni suivi. Les bulletins ne couvrent que les malwares déjà signalés. Formant Review vérifie aussi chaque pull request avec nos propres données sur les menaces.

Paquet Version OSV ID

Supprimez ou remplacez ces paquets dès maintenant. , ou utilisez Formant Review pour détecter les malwares dans les pull requests avant qu’un bulletin existe.
