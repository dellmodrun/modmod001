# Security

The Hacktron team are security researchers themselves, and Hacktron takes security seriously. It does not have a formal bug bounty or vulnerability disclosure program yet.

## Report a vulnerability

If you find a vulnerability in Hacktron, report it privately to [hello@hacktron.ai](mailto:hello@hacktron.ai).

Hacktron investigates every report and works to fix the issue as soon as it can. Each reporter is credited in the [hall of fame](#hall-of-fame).

Hacktron is grateful to these security researchers for helping improve its security.
