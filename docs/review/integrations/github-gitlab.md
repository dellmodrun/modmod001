# GitHub and GitLab

## Prerequisites

Your organisation needs an active GitHub, GitLab, Azure DevOps, or Bitbucket integration. Each provider's page covers connecting it and choosing the repositories to review.

:::tiles
- [GitHub](/docs/platform/repositories/github): Repository access for GitHub.com.
- [GitLab](/docs/platform/repositories/gitlab): Connect GitLab.com or self-hosted GitLab.
- [Azure DevOps](/docs/platform/repositories/azure-devops): Connect Azure DevOps Services or Server.
- [Bitbucket](/docs/platform/repositories/bitbucket): Connect Bitbucket Cloud.
:::

## Link your GitHub or GitLab identity

Hacktron recognises you on GitHub or GitLab once you link that identity to your Hacktron account. Link it to enable Review for an existing Hacktron account, or to link an existing auto-assigned Review seat to a Hacktron account.

::::steps

### Open the Account page

Click your organisation name in the top left corner and go to **Account**.

### Connect GitHub or GitLab

Scroll down to **Connected accounts** and click **Connect** next to **GitHub** or **GitLab**.

![Connected accounts, with a Connect button next to GitHub, Slack, and GitLab](https://www.hacktron.ai/shots/review/integrations/github-gitlab/connected_accounts/light.089b5897.webp)

### Authorise Hacktron

Sign in to GitHub or GitLab and approve the requested access.

### Return to Hacktron

After authorisation, Hacktron sends you back to **Account**.
