    Tools

    These tools let your AI assistant work with Formant. Each one has a REST API endpoint with the same operation and the same permission requirements.

    Viewers can read scans and findings. Members can update findings and prepare pentests. Starting a pentest or changing the Review settings needs an organisation admin.

    Scans and findings

    Tool Description
    list_scans
    GET /scans    		 List scans with their finding counts by severity
    get_scan
    GET /scans/{id}    		 Get the details of a scan
    export_findings
    GET /scans/{id}/findings/export    		 Export a scan’s findings as JSON, CSV, or SARIF
    stop_scan
    POST /scans/{id}/stop    		 Stop a running scan or pentest
    list_findings
    GET /findings    		 List findings across your organisation
    count_findings
    GET /findings/counts    		 Count findings by severity, state, and repository
    get_finding
    GET /findings/{id}    		 Get the details of a finding
    update_finding
    PATCH /findings/{id}    		 Change a finding’s state or severity
    add_finding_comment
    POST /findings/{id}/comments    		 Post a comment on a finding

    Whitebox

    Tool Description
    list_repositories
    GET /repos    		 List the connected repositories
    request_archive_upload
    POST /archives/uploads    		 Get a URL to upload a code archive to
    create_pentest_draft
    POST /pentests    		 Create a draft with code and optional live sites
    update_pentest_draft
    PATCH /pentests/{id}    		 Change a pentest that hasn’t started
    verify_pentest_login
    POST /pentests/{id}/login-checks    		 Check that Formant can sign in to each site
    estimate_pentest
    POST /pentests/{id}/estimate    		 Estimate a draft pentest’s credit cost
    get_cost_estimation
    GET /cost-estimations/{id}    		 Get a pentest’s cost estimate
    get_credit_balance
    GET /credits    		 Read your organisation’s Whitebox credit balance
    start_pentest
    POST /pentests/{id}/start    		 Start a pentest and spend its credits (admins only)
    discard_pentest_draft
    DELETE /pentests/{id}    		 Delete a pentest that hasn’t started

    Review

    Tool Description
    get_pr_review_settings
    GET /pr-review-settings    		 Read your organisation’s PR review settings
    update_pr_review_settings
    PATCH /pr-review-settings    		 Change the review comments, the check’s severity threshold, and the filters (admins only)
    set_pr_reviews
    POST /repos/pr-reviews    		 Turn PR reviews on or off for repositories (admins only)

    Warning

    For signed-in testing, your assistant sends the login details to Formant, which stores them encrypted. Anything you type in the conversation also goes to your assistant’s model provider. Use dedicated test credentials.

    Related

    When you create an API key, you choose its access scopes. The REST API offers these operations to your own scripts and applications too.
