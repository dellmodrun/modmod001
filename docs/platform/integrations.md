# Integrations

## Git providers

::::steps

### Start a free trial

[Sign up](https://app.hacktron.ai/signup) for a 14-day free trial of Formant.

### Connect your Git provider

Connect your GitHub Team, GitHub Enterprise Cloud, GitHub Enterprise Server, GitLab, Azure DevOps, or Bitbucket account. You choose exactly which repositories Formant can access.

Each provider has its own guide. GitHub covers GitHub Team and GitHub Enterprise Cloud, and GitHub Enterprise Server covers a self-hosted server. GitLab works with any plan on cloud GitLab.com and with self-hosted GitLab, Azure DevOps with Azure DevOps Services or Server, and Bitbucket with Bitbucket Cloud.

:::tiles
- [GitHub](/docs/platform/repositories/github): Repository access for GitHub.com.
- [GitHub Enterprise Server](/docs/platform/repositories/github-enterprise-server): Connect a self-hosted GitHub server.
- [GitLab](/docs/platform/repositories/gitlab): Connect GitLab.com or self-hosted GitLab.
- [Azure DevOps](/docs/platform/repositories/azure-devops): Connect Azure DevOps Services or Server.
- [Bitbucket](/docs/platform/repositories/bitbucket): Connect Bitbucket Cloud.
:::

::::

## Project management apps

Connect Jira or Linear so Formant can create issues for approved security findings, and remediation work stays in the tools your team already uses.

::::steps

### Open Issue tracking

In Formant, go to **Integrations** and find the **Issue tracking** section.

### Connect your issue tracker

Choose the app your team uses for remediation work.

:::tiles
- [Jira](/docs/platform/project-management/jira): Create Jira tickets for findings.
- [Linear](/docs/platform/project-management/linear): Create Linear issues for findings.
:::

### Configure ticket defaults

After the app is connected, save the default project, issue type, team, or project settings Formant should use when it creates tickets.

::::

## Communication apps

Connect Slack so Formant can send notifications to your team.

::::steps

### Open Communication Apps

In Formant, go to **Integrations** and find the **Communication Apps** section.

### Connect your communication app

Choose the app your team uses for communication. [Slack](/docs/platform/communication-apps/slack) covers sending notifications to Slack.

### Configure notification settings

After the app is connected, configure Formant's notification settings.
