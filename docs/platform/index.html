    Quickstart

    Create your organisation

    Sign up to create your organisation in Hacktron.

    Invite your team

    During onboarding, invite your team to the organisation with an invitation email.

    Connect your Git provider

    Connect GitHub Team, GitHub Enterprise Cloud, GitHub Enterprise Server, GitLab, Azure DevOps, or Bitbucket so Hacktron can access your code. Repositories covers each provider.

    Start the free trial

    Every organisation gets a 14-day free trial.

    Work with us in Slack

    This step is optional. Create a Slack channel with the Hacktron team to give feedback and get direct support.

    Note

    The invitation appears only when you sign up with a work email address.

    Next steps

    Review Whitebox API overview

    If you need an integration Hacktron doesn’t support yet, contact us and we’ll share the roadmap.
