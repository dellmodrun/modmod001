Formant Automations

Review und Whitebox finden Schwachstellen schneller, als die meisten Teams sie beheben können. Automations übergibt jeden neuen Befund, der Ihren Regeln entspricht, an einen Formant-Agenten, der prüft, ob der Befund echt ist, ihn behebt, Ihre Tests ausführt und einen Pull Request zur Prüfung durch Ihr Team öffnet.

Demo buchen oder Remediation-Leitfaden lesen.

Behebung

Der Agent testet zuerst, ob sich der Befund in Ihrem Code ausnutzen lässt. Wenn nicht, bleibt der Code unverändert, und der Lauf hält den Grund fest. Wenn ja, nimmt der Agent die kleinste Änderung vor, die die Ursache behebt, führt die Tests des Repositorys aus und ergänzt Regressionstests für den Fix.

Pull Requests

Der Pull Request landet dort, wo der Bug herkam, auf GitHub, GitLab, Azure DevOps oder Bitbucket.

Regeln

Ein Admin der Organisation richtet eine Automation einmal ein, und sie läuft ab dann bei jedem Treffer.

Fragen

Pusht es in unseren Code?

Es pusht auf einen eigenen Branch und öffnet von dort einen Pull Request. Es mergt nie.

Welche Befunde starten einen Lauf?

Neue Befunde, die einer aktivierten Automation entsprechen. Jeder Befund bekommt höchstens einen Lauf. Jedes Mitglied kann mit Remediate einen Lauf für einen älteren Befund starten.

Was ist der Unterschied zu Fix with AI in Review?

Fix with AI übergibt den Befund an den Editor eines Entwicklers. Bei Remediation erstellt der Agent von Formant den Fix, sodass niemand den Befund übernehmen muss.

Was kostet ein Lauf?

Läufe verbrauchen Automation-Credits aus einem gemeinsamen Guthaben der Organisation, abgerechnet, wenn ein Lauf abgeschlossen ist. Die Kosten hängen vom Umfang des Laufs ab, und jede Umgebung kann eine Obergrenze haben.
