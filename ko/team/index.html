Zayne Zhang

최고경영자

Zayne Zhang은 Hacktron의 공동 창업자이자 CEO입니다. Node.js HTTP 파서의 CVE 3건을 포함해 15건의 CVE에 이름을 올렸으며, 2022년 싱가포르 국방부 버그 바운티와 싱가포르 정부의 비공개 프로그램 3개에서 1위를 차지했습니다. 2023년과 2024년 DEF CON CTF 결승에서 Blue Water 소속으로 2위에 올랐고, 싱가포르 1위 CTF 팀인 Social Engineering Experts를 창립했습니다. 이전에는 TikTok에서 보안 연구를, Cure53에서 감사를 수행했습니다. 싱가포르군 사이버 방어 학교에서 커리어를 시작해 동기 중 수석으로 졸업했습니다. 케임브리지 대학교에서 컴퓨터 과학을 공부하며 최우등 성적을 거두었고, 이후 학업을 그만두고 Hacktron을 창업했습니다.

Harsh Jaiswal

최고연구책임자

Harsh Jaiswal은 Hacktron의 공동 창업자이자 최고연구책임자입니다. Meta와 Apple 서버에서 찾은 원격 코드 실행 취약점으로 각각 115,000달러와 50,000달러의 포상금을 받았습니다. Hacktron에서는 Mohan과 함께 CVSS 점수 9.9의 BeyondTrust Remote Support 인증 전 RCE인 CVE-2026-1731을 발견했습니다. 직원들의 ChatGPT 및 Codex 계정을 통해 OpenAI 내부 코드 저장소에 도달한 연구와, Bash를 호스팅하는 GNU Savannah에서 root 권한을 얻은 감사를 이끌었습니다. 이전에는 ProjectDiscovery에서 보안 연구원으로 일하며 GitHub Enterprise, GitLab, Ivanti, Kubernetes Ingress-NGINX의 치명적인 취약점을 공개했습니다. 그 전에는 Vimeo와 Zomato에서 보안 엔지니어로 일했습니다. 2016년 HackerOne에서 버그 헌팅을 시작했습니다.

TU Berlin에서 컴퓨터 과학 석사 학위를 받았습니다.
