Formant vs XBOW
vs

XBOW는 승인한 웹 애플리케이션과 API를 인터넷에서 공격합니다. Formant Red는 외부 서비스와 인증부터 SaaS 제공업체와 공급망까지 조직 전체를 다루며, 새로운 자산이 나타나는 즉시 테스트합니다. Formant Whitebox는 소스 코드를 기반으로 애플리케이션 하나를 침투 테스트하며, 50달러부터 시작합니다.

비교
Formant XBOW
범위 조직 전체: 외부 서비스, 인증, SaaS 제공업체, 공급망, 기능, 구성 요소. 인터넷에 노출된 웹 애플리케이션과 API.
자산 탐색 공유해 주신 소수의 자산에서 출발해, 아무도 목록에 올리지 않은 자산까지 나타나는 즉시 계속 찾아냅니다. 승인한 대상을 테스트합니다. 자산 목록이 없으면 XBOW 팀이 계약 기간 중 외부 애플리케이션을 찾아냅니다.
테스트 연구원이 입증한 모든 기법은 워크플로가 되고, 에이전트가 이를 환경 내 일치하는 모든 부분에 24시간 실행합니다. 자율 에이전트가 병렬로, 지속적으로 또는 필요할 때 실행됩니다. 기본은 블랙박스이며, 자격 증명, API 명세, 소스 코드를 추가할 수 있습니다.
발견 사항 치명적인 공격 경로를 입증하는 즉시 보고하며, 모든 단계의 요청, 응답, 증거를 제공합니다. 각 발견 사항마다 작동하는 익스플로잇과 요청 및 응답, 재현 단계, 연결된 공격 경로를 제공합니다.
수정 같은 유형의 공격을 막는 설계, 아키텍처, 격리 변경을 제안하고, 공격을 다시 실행해 경로가 차단되었는지 확인합니다. 코드 수정 제안을 티켓 관리 도구로 보내며, 재테스트는 무료로 무제한입니다.
감독 연구원이 에이전트를 모니터링하며 파괴적인 작업은 금지됩니다. 테스트가 가용성에 영향을 줄 수 있으면 중단하고 연락드립니다. 공격을 사람이 조종하지 않습니다. XBOW 팀이 계약을 관리합니다.

침투 테스트 Whitebox, 50달러~25,000달러, 코드 10만 줄당 약 500달러. 플랫폼에 포함.

자주 묻는 질문

Hacktron으로 무엇을 얻을 수 있나요?

Red는 외부 서비스와 인증부터 SaaS 제공업체와 공급망까지 조직 전체를 테스트합니다. 입증된 각 경로에는 모든 단계의 증거와 그 경로를 차단하는 설계 변경 권장 사항이 함께 제공되며, 이후 Hacktron이 공격을 다시 실행해 확인합니다. Whitebox는 소스 코드 기반 침투 테스트를 더하며, 50달러부터 시작합니다.

Whitebox 침투 테스트에는 무엇이 포함되나요?

소스 코드를 기반으로 애플리케이션 하나를 침투 테스트하며, 배포된 앱에 대한 동적 테스트는 선택 사항입니다. 기술 보고서와 경영진 보고서, 수정 가이드, 확인서, 무료 재테스트 1회를 제공하며, 이는 SOC 2, ISO 27001, 고객 보안 심사를 위한 침투 테스트 증빙으로 사용됩니다. 비용은 50달러~25,000달러로, 코드 10만 줄당 약 500달러입니다.

테스트는 안전한가요?

네. 파괴적인 작업은 금지되며, 연구원이 에이전트를 모니터링하고, 테스트가 가용성에 영향을 줄 수 있으면 중단하고 연락드립니다.

침투 테스트와 무엇이 다른가요?

침투 테스트는 고정된 범위를 한 번 테스트합니다. 레드팀 테스트는 상시 실행되므로, 새로운 자산과 새로 공개된 취약점이 나타나는 즉시 테스트됩니다.
